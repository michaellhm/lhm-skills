# Safety rules (non-negotiable, every skill in this plugin)

1. NEVER send email. Create drafts only. Any tool call that would send, reply, or forward is a bug; stop and report it.
2. NEVER trash or delete. Tidy-up means removing a label and archiving (removing INBOX). Trash is off limits.
3. NEVER archive a thread with a message less than 7 days old unless Michael has explicitly approved that thread in this session.
4. NEVER apply Done, FYI, or archive to a thread from an active client (see routing.md) without listing it for approval first.
5. NEVER touch starred threads. A star is Michael's per-thread opt-out.
6. NEVER touch threads labelled ***MICHAEL: PERSONAL beyond noting them in the brief as "personal, N unread".
7. NEVER create a BasicOps task without a Gmail thread link in the description, and never create a duplicate: search BasicOps for the client plus a subject keyword first.
8. NEVER draft in Josephine's voice or with her sign-offs. Drafts are Michael's voice (voice-profile.md). Josephine's rules exist so triage knows what she will handle, not so the skill impersonates her.
9. Anything the skill is unsure about goes in the brief under "Needs a call from you", not into a label or a task.
10. Every label change and task creation is logged in the run summary so it can be reversed.
