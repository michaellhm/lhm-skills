# Acceptance cases

Use synthetic inputs for a dry run; do not mutate live clients. These cases test decisions, not exact wording. A real second-client pilot remains required before claiming live workflow acceptance.

| Input scenario | Required observable output |
|---|---|
| Two-location client: North has open Month 0 attributes and verified baseline; South is Month 2. Both use one website. | Separate stages; North close-out checklist; baseline reused; one shared website/content plan with local links. No single invented client phase. |
| Tracker marks Month 0 complete; same-date update says architecture blocked; map file exists. | Inspect the map and authority/completion evidence; stage disputed until resolved. No automatic restart or blind complete status. |
| Booking events fall from 20 to 12; tagged sessions fall; search impressions rise; some query positions improve. | Label event definition, scope and confidence; investigate devices, clicks and tracking. Do not assert ranking caused the booking fall. |
| GA4 works; Ads direct access and comparable Maps scans unavailable; GA4 linked Ads-query events exist. | Explicit source coverage gaps; label fallback as events, not Ads CPA; no invented Maps trend or paid scan; useful scoped actions continue. |
| Green client has a converting paid query whose matching organic service page is weak. | Evidence-backed opportunity in the goal-led queue; no automatic duplicate page and no claim that paid conversion rate transfers to organic. |
| One location unknown; main growth location has routine work; another has a historical wrong phone flag. | All locations visible; current verification of urgent phone flag precedes routine work; unknown remains unknown; main focus retained thereafter. |
| Directory correction submitted but not published; posts generated but unscheduled. | Submitted/pending and generated statuses preserved. No phase completion or publication claim. |
| Report is saved locally but Drive upload/readback fails. | Return needs_review with delivery gap; no claimed Drive success and no fabricated link. |
| User asks only for a report. | Save requested report pack and state references; no messages, assignments, website changes or recurring schedule. |
