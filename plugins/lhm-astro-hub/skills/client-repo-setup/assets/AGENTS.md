# {{client_name}} website

This repo is the {{client_name}} website, plus the brain that explains how to write for it. Local Health Marketing (LHM) built it. You are helping someone from {{client_name}} review or edit their site.

## How this repo is set up

- `README.md`: setup steps for the person you are helping. Read it first.
- `brain/`: what we know about the business and how its copy is written. Always start with `brain/Overview.md`, which links to every other note.
- `skills/`: step-by-step workflows. Use them instead of improvising:
  - `start-website`: get set up and see what is waiting for review
  - `review-website`: review pages and record decisions
  - `share-preview`: share a preview link
  - `finish-review`: send the finished review back to LHM
- `site/`: the Astro website. Page copy lives in its content files.

## Rules

- Before writing or editing any copy, read `brain/Overview.md`, then `brain/Content Rules.md`, and follow them, including the anti-AI writing section.
- Check facts (services, staff, clinics, fees) against the brain. A line starting `> gap:` means we don't know yet. Ask, don't guess.
- Keep the client's own words where they've written them. Don't rewrite approved pages unless asked.
- Australian English. No em or en dashes.
- Ask before deleting files or changing anything outside `site/`.
- Never paste passwords or tokens into chat.
