# Start Prototype

1. Read `references/website-departmental-delivery.md` and validate the envelope.
2. Inspect the canonical client folder and existing artefact. Preserve history and established design.
3. Route sitemap work to `sitemap-architect`; homepage mock work to `html-prototype`; use both only when required.
4. Save the canonical artefact in the client folder.
5. Publish only when explicitly approved, using the exact repository, branch and client path.
6. Invoke `website-delivery-qa` and return the departmental handback.

A sitemap must be produced through `sitemap-architect`; generic prose is not sufficient. A local artefact without observed commit and URL is not live.
