- (2026-07-27) Service discontinuation is a distinct change type with no new value to substitute in, so the find-and-replace flow in Step 3 does not apply. Handle it as a removal: forward-looking artefacts get the reference stripped or redirected, historical records stay untouched.

Only the first group gets edited. Editing the second rewrites history and destroys the audit trail.
