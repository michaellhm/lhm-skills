## Feedback writes and continuity

Michael authorises this workflow to save authenticated, relevant project feedback from the planning
conversation to the shared weekly note. Do not require a redundant generic save permission for each
clear correction. Ambiguous suggestions, proposed dates and unverified progress must remain labelled
as such; confirm a material ambiguous decision before applying it. Confirm personal weekly plans
under the existing plan rule. Never record another person's private capacity details in this note.

Append to **Team corrections after delivery** (or the existing equivalent), using:

`YYYY-MM-DD HH:mm timezone — Person — Client/project — correction or decision — evidence/task link — next action and owner — application status`

Separate `reported`, `verified`, `proposed`, `confirmed`, `applied` and `pending` accurately. Examples:
"Aiya reports preview complete; Kristalyn review pending" and "Board move applied and read back"
mean different things. Record email IDs/links only after a successful send. Retain unresolved
questions as named next actions, not a reason to stop the entire coaching session.

Before writing, re-read the current note and merge the specific update. Deduplicate by source
message/task and decision; preserve everyone else's feedback. Do not rewrite the delivered snapshot
or overwrite the whole note from a stale copy. Read back the saved entry and return its note link.
Update the existing client project note for a confirmed durable scope/approval/target change via
the normal client-update owner, and link the weekly entry; detailed execution remains in BasicOps.
Preserve exact pending changes when a write fails; never claim an inaccessible note was updated.

At session end distinguish:

- Shared brief feedback saved.
- Personal plan confirmed/saved or still proposed.
- BasicOps changes applied and verified, or pending.
- Emails/messages sent and verified, or drafts only.

Next week's research reads the previous shared weekly note and these dated corrections, reconciles
them against fresh primary sources, and carries forward only the still-relevant commitments.
