# Internal Handover Document Template

Save as: `20 Clients/<Client>/project-management/Handover YYYY-MM-DD.md`

    # <Client> — Handover: <from> → <to> (<date>)

    ## Purpose
    One paragraph: who is taking ownership of what, and what the delegator
    retains (e.g. strategy, final review, major decisions).

    ## Package & Commercials
    Package sold, monthly fee, add-ons, billing status. (Values from the
    sales call / GHL deal — cite team-roster.md canonical pricing.)

    ## Per-project blocks (repeat per active project)
    ### <Project name>
    - **Current status:** one–two lines.
    - **Outstanding work:** bullet list; owner inline per bullet.
    - **Primary contacts:** client-side names + comms rules
      (e.g. "CC Liz on all key communications").
    - **Upcoming meetings:** date + attendees.
    - **<New owner>'s responsibilities:** bullets.
    - **<Delegator>'s responsibilities:** bullets.
    - **Success outcome (REQUIRED):** explicit definition of done.

    ## Institutional knowledge (REQUIRED — interview the salesperson)
    Client quirks, promises made, red flags, what's been tried and failed,
    comms preferences. This section may not be empty.

    ## Access & credentials
    By reference only: password-manager entry names, never actual secrets.

    ## First actions
    The first three concrete actions for the new owner, with dates.
