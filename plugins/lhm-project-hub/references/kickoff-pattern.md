# Kickoff Pattern (all kickoff skills follow this)

1. INTAKE — ask the service's 3–5 scope questions (defined per skill),
   one at a time. Always include: "What is the go-live / launch deadline?"
   (needed for backwards scheduling).
2. STATE — create the process state file in project-management/ (per skill),
   and add the current-projects.md block (folder-convention.md format).
3. SCAFFOLD — create the BasicOps project/task with phase subtasks and
   BACKWARDS-SCHEDULED due dates: start from the deadline, assign each
   preceding milestone a due date working backwards (Project Planning SOP
   method). Include owners from team-roster.md.
4. COMMS — draft the client kickoff email from templates/kickoff-emails.md
   (draft only).
5. HANDOFF — invoke or direct the user to the specialist owner (per skill),
   and report: state file created, BasicOps link, email drafted, next action.

Rules: global guardrails apply (see any project-hub skill's Rules section).
A kickoff NEVER does delivery work itself.
