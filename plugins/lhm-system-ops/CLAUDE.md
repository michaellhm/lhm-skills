# LHM System Ops

Use this plugin for capability incidents and goal-linked technical improvements to Hermes and the LHM plugin stack.

- Preserve the original business parent and production return point.
- Research native capability before proposing another dependency.
- Work only on a feature branch; never push directly to protected `main`.
- Separate Research, Engineering, QA and Security/Reliability evidence.
- Deploy only an immutable approved commit through the root-owned installer.
- A technical change is not complete until the original parent resumes and its acceptance test passes.
