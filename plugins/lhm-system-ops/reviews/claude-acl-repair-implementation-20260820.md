## Capability Researcher

unprivileged worker boundary, but only once before starting an asynchronous unit. A later ACL mask
reset could therefore remove effective execute traversal while Claude was still running. Native
systemd transient execution, POSIX ACL tools, and the existing tracked dispatcher are sufficient;
no dependency, credential, network access, third-party plugin, or broader permission is needed.

## Platform Engineer

Release 0.8.1 makes the root transient unit run the dispatcher in a closed `--supervise` mode. It
validates a canonical existing child of the runs root, launches the worker through `runuser` as
`claudeworker`, reapplies the exact two-ancestor execute-only ACL every 250 ms, terminates on ACL
maintenance failure, and supplies an honest durable failed terminal artifact when necessary.
The worker retains write access only to its validated run directory. CAP-015 source and predecessor
hashes are pinned in the release manifest. The governed installer backs up exact bytes, uid/gid,
mode, and ancestor ACL text; install exceptions automatically roll back.
