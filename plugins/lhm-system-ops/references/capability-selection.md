# Capability selection standard

| Order | Candidate | Default decision |
|---|---|---|
| 1 | Native Hermes capability | Activate/configure when maintained and permission-fit |
| 2 | Installed LHM capability | Repair registration or configuration |
| 3 | Official integration | Prefer when maintained by the platform/provider |
| 4 | Third-party plugin | Require provenance, maintenance and security review |
| 5 | LHM plugin implementation | Build reusable capability with tests |
| 6 | Protected-host component | Last resort; exact consequential approval required |

Web and YouTube failures follow the same ladder. Record whether the need is retrieval, transcript extraction, browser control, authentication, media processing or source verification; these are different permission classes.
