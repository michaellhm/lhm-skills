# Codex execution bridge release contract

This additive bridge supersedes any inactive generic `lhm-codex-dispatch.path` contract. The CTO plugin dispatcher remains separate. Hermes may submit and read receipts through `lhm-codex-dispatch`; it never receives the worker credential or inference environment.

Install only from an approved immutable plugin release: install the container client at `/opt/data/profiles/lhm_brain/bin/lhm-codex-dispatch`, the host worker at `/usr/local/libexec/lhm-codex-execution-worker`, and both units root-owned. Create `incoming` as `root:hermes` mode `0770`, `receipts` and `incidents` as `codexworker:hermes` mode `0750`, and `processing`, `failed`, and `worker-runs` as `codexworker:codexworker` mode `0700`. At every worker launch the root-owned service preflight restores only `mask::--x,user:codexworker:--x` on `/home/hermes/.hermes`, `/home/hermes/.hermes/profiles/lhm_brain`, and the queue root before dropping to codexworker; `-n` prevents implicit mask recalculation and no recursive, unrelated named-user, profile, or vault ACL is allowed. Enable `lhm-codex-execution.path`. Explicitly disable the obsolete `lhm-codex-dispatch.path` if present. Do not stop the Telegram gateway.

Before enabling, run `runuser -u codexworker -- env -i HOME=/home/codexworker CODEX_HOME=/home/codexworker/.codex PATH=/home/codexworker/.local/bin:/usr/bin:/bin /home/codexworker/.local/bin/codex login status` and retain only whether it reports ChatGPT login. Never retain credential output. Smoke-test generic, marketing, auth-failure, invalid-profile, duplicate, timeout and existing Claude/repository routes. Compare metering before/after the controlled regression; zero new OpenRouter generations and no hermes-2 worker inference are required live evidence.

Rollback: disable `lhm-codex-execution.path`, wait for the oneshot worker to exit, restore the recorded prior unit/file inventory (including the prior service bytes without the launch preflight), restore the three recorded pre-install ACLs byte-for-byte with `setfacl --restore`, remove only the replacement assets that were previously absent, daemon-reload, and re-enable the prior healthy watchers. Keep receipts/incidents for audit. This does not authorise Hermes or OpenRouter to perform substantive work while Codex is unavailable.
