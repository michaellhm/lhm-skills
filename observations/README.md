# Team Observation Logs

Synced Task Observer logs from each team member's machine, one folder per person, one subfolder per workspace:

```
observations/<person>/<workspace-slug>/log.md
observations/<person>/<workspace-slug>/cross-cutting-principles.md
```

- **Written by:** the `sync-observations` skill (lhm-skill-ops plugin), typically via each person's weekly local routine.
- **Read by:** the `weekly-skill-review` skill, which turns OPEN observations into a skill-update PR.
- **Do not edit by hand** — statuses here are managed by the review; content fidelity is managed by sync.

These logs may reference client work. This repo is private; keep it that way.
